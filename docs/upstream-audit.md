### What #35 covers

Its code overlaps #8/#17/#26/#27, #28–31 and #33. It does not include #34's binding fix, #20's Japan upload route or the fork's #19 Drive override and suffix map. With `tld='uk'`, it still constructs `www.amazon.uk`. With `init_folders=False` or `init_db=False`, original upload code can dereference a missing tree or database. Tests exercise the lightweight constructor through listing and uploading.

### Issues and downstream reports

- US and regional cookie spellings can lead to invalid hosts or 401, and may mask later failures. The maintainer favored direct cookie mappings over implicit environment loading. [#3](https://github.com/trevorhobenshield/amazon_photos/issues/3), [#4](https://github.com/trevorhobenshield/amazon_photos/issues/4), [#7](https://github.com/trevorhobenshield/amazon_photos/issues/7), [#11](https://github.com/trevorhobenshield/amazon_photos/issues/11), [#12](https://github.com/trevorhobenshield/amazon_photos/issues/12), [#22](https://github.com/trevorhobenshield/amazon_photos/issues/22), [#24](https://github.com/trevorhobenshield/amazon_photos/issues/24)
- Japan prompted PR #20. German uploads succeeded after adopting the EU CDProxy URL, and a French account needed the EU host ending in `.com`. The German report also observed a different browser upload protocol with an access-token header. [#9](https://github.com/trevorhobenshield/amazon_photos/issues/9), [#10](https://github.com/trevorhobenshield/amazon_photos/issues/10)
- #6 concerns missing checksum metadata, #13 asks for lightweight initialization, #14 asks for 3.9 support and #15 reproduces the missing Parquet engine. Modern Python support, remote checksum matching, and lazy initialization address the applicable cases. [#6](https://github.com/trevorhobenshield/amazon_photos/issues/6), [#13](https://github.com/trevorhobenshield/amazon_photos/issues/13), [#14](https://github.com/trevorhobenshield/amazon_photos/issues/14), [#15](https://github.com/trevorhobenshield/amazon_photos/issues/15)
- Folder selection, async uploads, download compatibility and date filtering are covered by the existing API, fixes and documented limits. A native public async client and reproducing web UI search semantics remain open. [#1](https://github.com/trevorhobenshield/amazon_photos/issues/1), [#2](https://github.com/trevorhobenshield/amazon_photos/issues/2), [#5](https://github.com/trevorhobenshield/amazon_photos/issues/5), [#23](https://github.com/trevorhobenshield/amazon_photos/issues/23)
- #21 is an unresolved refresh question. #32 identifies the MCP integration and the related PR series. [#21](https://github.com/trevorhobenshield/amazon_photos/issues/21), [#32](https://github.com/trevorhobenshield/amazon_photos/issues/32)
